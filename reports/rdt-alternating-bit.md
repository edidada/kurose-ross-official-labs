# Kurose/Ross RDT：Alternating Bit

来自教材9e官网当前指向的2022 Python lab_only起点，仅补全EntityA/EntityB区。实现停止等待交替位、发送队列、CRC32覆盖序号/确认号/20字节载荷、超时重传、丢失ACK后的重复抑制。状态全为每个实体实例变量，使用0/1两种序号，满足官方seqnum_limit>=2接口。

独立yml在GitHub Actions运行原网络模拟器60组参数（12种种子×5组丢包/损坏，含60%丢包），每组200条应用消息，逐字节检查最终按序、无重复、无遗漏，另测空流和1500次消息/反复序号绕回。连续模拟验证实体状态不跨实例泄漏。

原Simulator.run在最后一条消息交给A时便停止，不等待传输完成；测试随后只分发其既有网络/定时事件，并丢弃后续应用生成事件，使在途消息排空。不修改原模拟器、不伪造ACK，不把原CLI报告中尚未排空的接收数称作最终送达率。此项为Alternating Bit，不声称已实现Go-Back-N或其他网络实验。本地未执行实验。
